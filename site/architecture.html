02

Decisões que já tomamosDecisions already made

SegurançaSecurity

  • Autenticação JWT e RBAC por perfil, checados no backendJWT auth and role-based RBAC enforced in the backend
  • Segredos só por variável de ambiente, nunca no repositórioSecrets only via environment variables, never in the repo
  • Documentação da API protegida por perfil admin em produçãoAPI docs protected behind the admin role in production
  • Upload com limite por streaming e rate limit em endpoints públicosStreaming upload caps and rate limits on public endpoints
  • Auditoria de toda mutação feita pelo painel de plataformaEvery platform-admin mutation is audited

EntregaDelivery

  • Migrations rodam antes da aplicação subir, no próprio composeMigrations run before the app starts, inside the compose file
  • Deploy automatizado com GitHub ActionsAutomated deploys with GitHub Actions
  • Runbooks de deploy e troubleshooting versionados no repositórioDeploy and troubleshooting runbooks versioned in the repo
  • Dev Containers para o ambiente ser igual em qualquer máquinaDev Containers so the environment is identical on any machine
  • Lint (ruff) e testes (pytest) no CI antes do mergeLint (ruff) and tests (pytest) in CI before merging

DadosData

  • Multi-tenant por coluna de organização, escopo aplicado em toda consultaMulti-tenancy by organization column, scope applied on every query
  • Soft delete e colunas de auditoria padronizadasStandardized soft delete and audit columns
  • Saída de LLM sempre em JSON validado antes de chegar à regra de negócioLLM output is always validated JSON before it reaches business logic

Automação desktopDesktop automation

  • Serviços como plugins que se registram no menuServices as plugins that register themselves in the menu
  • Credenciais só em memória, TLS sempre verificadoCredentials kept only in memory, TLS always verified
  • Distribuição de versões com checagem SHA-256Version distribution with SHA-256 checks
