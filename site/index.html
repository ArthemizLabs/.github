03

Como trabalhamosHow we work

Regras aplicadas hoje nos repositórios, não promessas. Rules applied in the repositories today, not promises.

Segurança desde o inícioSecurity from day one

JWT com RBAC, segredos só por variável de ambiente, TLS verificado e auditoria de segurança antes de cada PR.JWT with RBAC, secrets only via environment variables, verified TLS and a security audit before every PR.

Decisões registradasRecorded decisions

Toda decisão técnica relevante vira registro com contexto, alternativas e reversibilidade.Every relevant technical decision is recorded with context, alternatives and reversibility.

Ambientes reproduzíveisReproducible environments

Docker Compose e Dev Containers do desenvolvimento à produção. Migrations versionadas com Alembic ou SQL numerado.Docker Compose and Dev Containers from development to production. Versioned migrations with Alembic or numbered SQL.

CI como porta de entradaCI as the gate

Workflows reutilizáveis de lint e testes neste próprio repositório de governança.Reusable lint and test workflows living in this governance repository.

Histórico legívelReadable history

Conventional Commits, branches com nome descritivo e PRs com resumo, impacto de segurança e testes.Conventional Commits, descriptively named branches and PRs with summary, security impact and tests.

Simples antes de distribuídoSimple before distributed

Monólito bem dividido primeiro. Microsserviços só quando houver motivo medido.A well-structured monolith first. Microservices only when there is a measured reason.
